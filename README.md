## Ringkasan Proyek

**OPREKCODE.ID — Jasa Website UMKM** adalah platform *landing page* promosi layanan pembuatan website profesional yang dirancang khusus untuk mendigitalisasi usaha mikro, kecil, dan menengah (UMKM). Website ini menyajikan informasi penawaran jasa, showcase portofolio, pilihan paket harga, serta jalur kontak langsung bagi calon klien.

> [!NOTE]
> Proyek ini dikembangkan menggunakan *pure frontend stack* (HTML, CSS, Vanilla JS) yang teroptimasi, ringan, dan di-deploy secara langsung melalui platform **Vercel**.

---

## Teknologi Utama

| Layer | Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Structure** | HTML5 | Semantik markup terstruktur dan teroptimasi SEO |
| **Styling** | CSS3 | Custom UI modern, CSS Grid, Flexbox, & CSS Variables |
| **Interactivity** | JavaScript (ES6+) | Logika navigasi interaktif & manipulasi DOM |
| **Deployment** | Vercel | Infrastructure hosting statis dengan CI/CD otomatis |

---

## Fitur Unggulan

- **Landing Page Modern & Interaktif** — Tampilan antarmuka profesional untuk meningkatkan kredibilitas brand dan *conversion rate*.
- **Informasi Paket Layanan** — Struktur informasi harga dan paket pembuatan website yang transparan dan rinci.
- **Showcase Portofolio Proyek** — Galeri tampilan karya website yang telah diselesaikan untuk meyakinkan calon pelanggan.
- **Responsif Sepenuhnya** — Penampilan konsisten dan optimal di berbagai layar (ponsel, tablet, & desktop).
- **Performa Instan (Zero Dependency)** — Pengunduhan halaman super cepat tanpa ketergantungan *framework* berat.
